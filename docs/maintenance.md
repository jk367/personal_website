# Maintaining jmkettle.com

This is a Hugo site with vanilla JavaScript and shared CSS in `assets/css/site.css`, inlined by the base template. The current build is tested with Hugo 0.154.5. Preserve the existing typography, page structure, and photographs.

## Source of truth

- `content/`: published writing and photo/event page metadata. Keep drafts unpublished.
- `data/site.yaml`: site identity, navigation metadata, social links, and featured writing.
- `data/posters.yaml`: Stop1 poster archive. Edition content lives under `content/events/stop1/`.
- `data/image_delivery.json`: measured image dimensions and responsive variants, generated by `scripts/prepare_images.py`.
- `layouts/`: Hugo templates and partials. `responsive-image.html` handles image delivery, intrinsic dimensions, and one-time fallback behavior.
- `static/_headers`: version-controlled response headers. `static/_redirects` preserves known old project URLs.
- `public/`: generated output; do not edit it or commit a local development build.

Older guides referring to `data/photos.yaml`, a live Projects section, or client-side random homepage photos describe an earlier version. Individual photographs are cataloged in their content files. The homepage photo selection is shuffled at build time; the homepage haiku uses today's entry at build time, otherwise the first archive entry.

## Before changing the site

Fetch the repository and compare your branch with `origin/main`. Published writing may be newer than a local checkout. Preserve unrelated local changes. Work on a feature branch and check the production build before publishing.

## Photography and posters

Keep original image URLs, Cloudflare IDs, and descriptive alt text in the content files. Gallery image, ID, and alt-text arrays must have equal lengths. Inspect each photograph before describing it. A gallery cover's accessible link name comes from its visible caption, so its name is not announced twice.

The Cloudflare `gridthumb` and `griddisplay` variants crop images. Do not use them for complete posters or gallery detail views. Adding `?width=...` to the fallback photo host does not resize an image. Flexible Cloudflare variants were unavailable when tested.

After adding or replacing an image, run:

```sh
python3 scripts/prepare_images.py
```

This command requires Python with AVIF-enabled Pillow, Ruby, curl, and network access. It reads published content, downloads image sources to the system temporary directory, and writes uncropped 480px/800px/1200px/1600px versions, capped at the source width. AVIF at quality 60 is preferred, with WebP at quality 78 as the browser fallback. Original gallery covers are resized from the existing cover source to preserve their composition. Pre-cropped Cloudflare covers retain their existing crop. Only optimized files belong in `srcset`: offering a large original caused high-density phones to download oversized files.

Use `--refresh` if an image was replaced at the same source URL. Every generated variant has a content hash in its filename, making the one-year immutable cache safe. Commit the generated manifest and its referenced files together. Normal Hugo builds require no image downloads, Python packages, or Cloudflare account settings. Do not remove old image files unless you have confirmed they are unreferenced and no longer need to support a cached page.

Check detail pages at mobile and desktop widths. Poster previews on Home, Events, and the Stop1 archive fill matching 27:35 frames with an approved CSS crop. Individual poster detail pages must preserve the complete source proportions and include all printed information. Photo grids may frame photographs using their existing CSS. Prefer original art over automatic re-cropping.

Only the opening homepage poster loads eagerly with high priority; the photographs farther down use native lazy loading. Check mobile performance with Lighthouse at both the default pixel density and 3x density, recording image bytes and Largest Contentful Paint. Use the same deployment and test conditions for comparisons; the homepage photographs shuffle between builds, so total page bytes can change with the selection. Inspect the resulting images as well as the score.

## Writing and haikus

Add `essay` to an essay's `writing_categories`, alongside any topic tags. The category controls link to generated category pages, so they work without JavaScript and preserve browser history/bookmarks.

The Daily Haiku archive remains in `content/writing/daily haikus.md`. Keep the existing date headings and poem formatting, newest first. Update `lastmod` to at least the newest poem date whenever adding entries. The validator rejects a stale modification date. Do not automatically rewrite poems or enforce syllable counts.

The writing template adds stable `#haiku-YYYY-MM-DD` anchors to date headings without changing paragraph spacing. The homepage haiku links to its corresponding date. Month navigation and new editorial selections were intentionally excluded from the functional fixes.

## Music and About

Playlist URLs and IDs live in the `soundcloud` front matter of `content/music/_index.md`. The SoundCloud shortcode reads them; do not duplicate URLs in embed markup. Keep a direct playlist link independent of each iframe. Autoplay is disabled. Without JavaScript, visitors can use the listening links; About disclosures reveal their existing content.

## Metadata and missing pages

`page-description.html` supplies page-specific search/social descriptions; explicit page descriptions take precedence. `page-title.html` distinguishes photos, series, events, and taxonomy pages in browser/search titles. It does not change individual artwork headings.

The root `404.html` prevents Cloudflare Pages from treating the site as a single-page application. Known former `/projects/stop1/` and `/projects/music/` URLs have explicit redirects. Never redirect arbitrary missing URLs to Home. Confirm actual HTTP status codes on the deployed preview; a successful Hugo build alone cannot prove hosting behavior.

One duplicate Content-Security-Policy header is added outside this repository. The user deferred investigation of that Cloudflare account setting on September 8, 2026. Keep the repository policy intact until the account rule can be inspected; do not weaken either policy speculatively.

## Verification

```sh
bash scripts/validate_site.sh
hugo server -D
```

The validation script builds into a temporary directory and checks JSON/JSON-LD, internal references, dates, gallery arrays, image files and aspect ratios, full Stop1 posters, essay discovery, caption rendering, 404 output, and haiku anchors. Use a non-draft server for the final preview. Check responsive navigation, photo sharpness, full poster proportions, keyboard controls, SoundCloud loading, and browser errors after template changes.
